# Purana: vintage & heritage objects from India (pilot)

- `research/product-market-fit.md`: product–market fit research, unit economics, compliance, 6-week validation plan.
- `research/alternatives.md`: 16 alternative product categories scored, top picks, what to avoid, test plan.

(or add Shopify Buy Button / PayPal) and replace the SVG illustrations with real product photography.
